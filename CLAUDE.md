# Working with Frame Parade

This repository is a configurable video-production kit. Its owner supplies the channel, material and decisions. Use the owner's language in conversation; project documentation is primarily English.

## Start here

- For a new setup, read KURULUM.md, KURALLAR.md and LICENSE before installing or producing anything.
- Ask the setup questions in kurulum/questions.md or kurulum/sorular.md, one topic at a time. Reuse answers already given.
- Runtime settings belong in existing kanal.json fields. Human preferences belong in yonetim/VIDEO-KIMLIGI.md, yonetim/referanslar.md and yonetim/ROLLER.md.
- Treat the local files and actual command results as evidence. Do not claim installation, rendering, audio quality or publishing succeeded without the corresponding result.

## Roles and production

Agree on who writes, produces, reviews and approves in yonetim/ROLLER.md. One model may perform distinct roles sequentially; additional roles do not automatically require more sessions or services.

For a video: agree on the topic and viewer benefit, prepare the title and script, outline scenes, review the design, produce a small local preview, then check the finished output using KALITE-KAPISI.md. Keep claims grounded in source material. Ask the owner to listen before accepting a new voice or effect.

The initial setup is a local silent portrait sample. Optional services can stay unconfigured. Follow LICENSE for allowed use and preserve third-party rights.

## Boundaries

Follow KURALLAR.md for source files, credentials, spending, account access and publishing. Existing authorization remains valid within its stated scope; do not repeatedly ask the same question. If an essential decision is missing, continue independent preparation and ask only for that decision.

Keep a short continuation note in the project's management records: completed work, real output paths, checks, unresolved issues and next step. Never include secrets. If the code and documentation disagree, report the exact mismatch and resolve it before relying on that step.
