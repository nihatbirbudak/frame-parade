# Contributing to Frame Parade

Contributions are welcome: bug fixes, clearer documentation, translations, templates and improvements to the video workflow.

## Before you contribute

Read [LICENSE](LICENSE). Frame Parade is source-available under the **Frame Parade Community Use License 1.0**. You may fork the project, modify it and share your version free of charge under that same license. Preserve notices and source attribution, identify your changes and provide the covered source code. Selling the kit, placing it in a paid bundle or offering prohibited commercial services is not permitted.

For a large change, open an issue describing the problem and your proposed approach before starting. Small, focused fixes can go directly to a pull request.

## Prepare a pull request

1. Fork the repository and make a branch for one focused change.
2. Follow the current project instructions. Use documented checks; do not invent a successful test result if you cannot run them.
3. Explain what changed, why it helps and how you checked it. Include a small before/after example when useful. For untested changes, state the limitation.
4. Include only material you are entitled to submit. Keep API keys, tokens, private channel data, personal footage and unlicensed media out of the contribution. Identify third-party material and preserve its license.
5. Open a pull request against the official repository. Review may lead to revisions; submission does not promise acceptance.
